Вопросы

FAQ

Куда вставить мой API?

Нажми «⚙ Настройки API» над студией. Там всего два поля: Base URL и токен. Сценарий, кадры и озвучка пойдут через один этот API. Если ты купил ключ у реселлера — у него в документации (или в личном кабинете) указан свой Base URL, вставь его вместе с токеном.

Какие API подходят?

Любой OpenAI-совместимый API: сам OpenAI, OpenRouter, GSM, ProxyAPI и прочие реселлеры — всё, что даёт адрес вида https://…/v1 и токен. Нужны три эндпоинта: /chat/completions (текст), /images/generations (картинки), /audio/speech (озвучка).

Это безопасно? Куда уходят ключи?

Токен сохраняется только в localStorage твоего браузера и отправляется напрямую в твой API — у сайта нет своего сервера-посредника. В любой момент удали его кнопкой в настройках.

Сколько стоит один ролик?

Только расход твоего API. Ролик на 30 секунд ≈ 1 текстовый запрос + 5 картинок + 5 коротких озвучек. На gpt-image-1 это порядка $0.2–0.5, на DALL·E 3 дешевле.

В каком формате экспорт?

Плеер записывает видео в WebM (VP9 + звук) прямо в браузере. YouTube и TikTok принимают его как есть; для MP4 прогони файл через любой конвертер. Кадры, обложка, озвучка и сценарий скачиваются по отдельности.

Можно ли без озвучки?

Да — сними галочку «Озвучка», и студия соберёт тихий ролик с субтитрами, а длительность рассчитает по тексту. Озвучку можно докрутить позже для отдельных сцен.

⚙ Твой API

Всего два поля — весь сайт (сценарий, кадры, озвучка) работает через этот один API. Токен хранится только в твоём браузере.

🔑 Подключение — любой провайдер
Модели — менять не обязательно

Сайт работает с любым OpenAI-совместимым API, не только с OpenAI. Токен и Base URL должны быть от одного продавца: где купил ключ — там же в кабинете/документации написан адрес API. Кнопки выше — просто примеры популярных.

Модели подбирай под своего провайдера: текст — gpt-4o-mini / glm-5.3 / …; картинки — gpt-image-1 / dall-e-3 / cogview-4 / …; озвучка — gpt-4o-mini-tts / tts-1. Если у провайдера нет озвучки — сними галочку «Озвучка» в брифе: ролик соберётся с субтитрами.
