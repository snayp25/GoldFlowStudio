# GoldFlow Studio

Сайт-студия, которая собирает вертикальные ролики (YouTube Shorts / TikTok / Reels) целиком:
сценарий → кадры → озвучка → субтитры → плеер → экспорт видео.

**Работает на твоём API: в настройках всего два поля — Base URL и токен.**
Сценарий, картинки и озвучка идут через один этот API. Токен хранится только
в localStorage твоего браузера, у сайта нет своего сервера.

## Как запустить

**Способ 1 (проще всего):** дважды кликни `index.html` — сайт откроется в браузере.

**Способ 2 (надёжнее, если API ругается на CORS при открытии с file://):**
запусти локальный сервер в папке сайта:

```
python -m http.server 8080
```

и открой в браузере http://localhost:8080

Выложить в интернет: просто закинь папку на любой статический хостинг
(GitHub Pages, Netlify, Vercel, обычный хостинг) — больше ничего не нужно.

## Как пользоваться

1. Открой сайт → появится окно «Твой API».
2. Вставь **Base URL** и **токен** (купленный где угодно), нажми «Проверить подключение».
3. Если у провайдера другие названия моделей — раскрой «Модели» и поправь
   (по умолчанию: `gpt-4o-mini`, `gpt-image-1`, `gpt-4o-mini-tts`).
4. Впиши тему ролика, выбери длительность/стиль/голос → «Сгенерировать ролик».
5. Жми ▶ для просмотра, «Записать видео» — WebM-файл со звуком скачается сам.
6. В списке «Скачать материалы»: сценарий с SEO, обложка 1080×1920, кадры, озвучки.

Какой-то кадр или озвучка не понравились — на карточке сцены жми 🎨 или 🔊,
перегенерируется только она.

## Какой API подходит

Любой OpenAI-совместимый, у которого есть три эндпоинта:

| Что | Эндпоинт | Модель по умолчанию |
|---|---|---|
| Сценарий | `POST /v1/chat/completions` | gpt-4o-mini |
| Кадры | `POST /v1/images/generations` | gpt-image-1 (или dall-e-3) |
| Озвучка | `POST /v1/audio/speech` | gpt-4o-mini-tts (или tts-1) |

Подходит сам OpenAI, OpenRouter, ProxyAPI, GSM и другие реселлеры —
вставь их Base URL (например `https://openrouter.ai/api/v1`) и купленный токен.

## Частые вопросы

- **Экспорт в MP4?** Браузер пишет WebM — YouTube/TikTok принимают его как есть.
  Для MP4 прогони через любой конвертер.
- **Ошибки при открытии с file://** — некоторые API не разрешают запросы с
  происхождения `null`. Запусти через `python -m http.server` (способ 2).
- **Кадры в стиле dall-e-3?** Поменяй модель картинок в настройках на `dall-e-3`.
